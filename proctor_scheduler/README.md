# ระบบจัดเจ้าหน้าที่คุมสอบ TBS (proctor_scheduler) — v1.0 (deploy-ready)

เครื่องมือจัดคิวคุมสอบอัตโนมัติด้วย **Google OR-Tools CP-SAT** — เกลี่ยเงิน/คิวให้แฟร์
ตามกฎที่ถอดจากไฟล์จริงของคณะ (ดูเอกสารวิเคราะห์ในโปรเจกต์)

## ติดตั้ง (ครั้งเดียว)
```bash
pip install ortools openpyxl
```
ต้องมี Python 3.10+ (เช็คด้วย `python3 --version`)

## ใช้งาน
```bash
python run.py \
  --schedule "ตารางสอน.xlsx" \
  --roster "คิวเดิม.xlsx" --sheet "กลางภาค1-69รังสิต2" \
  --type midterm --campus "รังสิต" --term "1/2569" \
  --exempt "ชื่อคนยกเว้น1,ชื่อคนยกเว้น2" \
  --demand-from-queue \
  --out "ผลจัดคิว.xlsx"
```

### พารามิเตอร์
| ธง | ความหมาย |
|---|---|
| `--schedule` | ไฟล์ตารางสอน (ใช้คำนวณ demand จาก enrollment) |
| `--roster` + `--sheet` | ไฟล์คิวเดิม + ชื่อชีท (ดึงรายชื่อเจ้าหน้าที่) |
| `--type` | `midterm` หรือ `final` |
| `--exempt` | ชื่อคนขอยกเว้นทั้งเทอม คั่นด้วย `,` |
| `--demand-from-queue` | อ่าน demand จริงจากชีทคิว (**แนะนำตอนนี้** — ดูหมายเหตุ) |
| `--time` | เวลา solve สูงสุด (วินาที, default 30) |
| `--out` | ไฟล์ผลลัพธ์ |

## ได้อะไรออกมา (ไฟล์ Excel 2 ชีท)
1. **ตารางคุมสอบ** — grid คน × คาบ (1=ถูกจัด) สีเหลือง/เขียว + คอลัมน์เงิน หน้าตาเดิม
2. **สรุปภาระรายคน** — เหลือง/เขียว/คิวรวม/เงิน + ไฮไลต์คนที่เบี่ยงจากเฉลี่ย >15%

## กฎที่ฝังในระบบ (ปรับได้ที่ `models.py`)
- ค่าตอบแทน: เหลือง 300 (นอกเวลา) / เขียว 100 (ในเวลา)
- เพดาน 65 คนสอบ/ห้อง · คนคุม 2 (≤18) / 3 (19-65)
- ลำดับความแฟร์: **เงินเท่ากัน > คิวเท่ากัน > เหลืองเท่ากัน** (ปรับน้ำหนักที่ `engine.py`)
- carry-forward ยอดสะสมข้ามเทอม (ตั้งที่ `Staff.carry_*`)

## ⚠️ หมายเหตุสำคัญเรื่อง demand
ตอนนี้แนะนำใช้ `--demand-from-queue` เพราะตัวคำนวณ demand จาก enrollment (per-section)
**นับเกินจริง** (สมมติแต่ละ section แยกห้อง) — ของจริงคณะรวมหลาย section ในห้องเดียว
→ ต้องยืนยัน "กฎการรวม section เข้าห้อง" ก่อนจึงจะคำนวณ demand จากตารางสอนได้แม่น (phase 2)

## โครงสร้างโค้ด
```
proctor_scheduler/
  models.py     # โครงสร้างข้อมูล + ค่าคงที่เชิงกฎ
  demand.py     # ตารางสอน/ชีทคิว -> Session + demand
  staff_io.py   # โหลดรายชื่อ + ยอดสะสม
  engine.py     # CP-SAT solver (หัวใจ)
  excel_io.py   # export Excel หน้าตาเดิม
run.py          # ตัวรันหลัก (CLI)
```

## รัน UI (สำหรับคนไม่เขียนโปรแกรม) ⭐
```bash
pip install -r requirements.txt
streamlit run app.py
```
เบราว์เซอร์จะเปิดหน้าจอให้เอง — ทำตาม 5 ขั้น:
1. แถบซ้าย: อัปโหลดตารางสอน + ไฟล์คิว → เลือกชีทรายชื่อ → กด "เริ่ม"
2. แท็บ "ปรับ demand": แก้จำนวนคนคุมต่อคาบ (ค่าประเมินเริ่มต้นให้แล้ว)
3. แท็บ "วันไม่ว่าง": เลือกคน → ติ๊กคาบที่ไม่ว่าง/ยกเว้น
4. แท็บ "จัดคิว": กดปุ่มจัด (ถ้าคนไม่พอจะเตือน)
5. แท็บ "ผล": ดูตาราง (แถวแดง=ควรตรวจ) → ดาวน์โหลด Excel

### ⚠️ demand เป็น "ค่าประเมิน" ต้องปรับ
ตารางสอนมีแค่ที่นั่งที่เปิด ไม่ใช่คนสอบจริง — ค่า demand เริ่มต้นจึง
ประเมินจาก (จำนวน section × คนคุม/ห้อง) ซึ่งมักเกินจริงในคาบพีค
ให้แก้ตัวเลขในแท็บ "ปรับ demand" ตามคนสอบจริงเมื่อทราบ หรือรวมห้อง/เพิ่มคาบชดเชย

demand ที่ได้ยัง "เกินจริง" เพราะตารางสอนมีแค่ที่นั่งที่เปิด (ทุกห้อง 40-50 → 3 คนคุม)
