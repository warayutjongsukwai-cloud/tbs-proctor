# คู่มือ Deploy — ระบบจัดคนคุมสอบ TBS

เลือก 1 ใน 3 วิธี ตามความสะดวก (เรียงจากง่ายสุด)

---

## วิธีที่ 1 ⭐ Streamlit Community Cloud (ฟรี, ได้ลิงก์ให้ทีมเข้าใช้)
เหมาะถ้าอยากให้เพื่อนร่วมงานเปิดจากลิงก์ ไม่ต้องลงโปรแกรม

**ครั้งแรก (ทำครั้งเดียว ~5 นาที):**
1. สมัคร GitHub (ฟรี) ที่ github.com — ถ้ายังไม่มี
2. สร้าง repository ใหม่ (ตั้งเป็น Private ได้) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
   (ลากไฟล์ทั้งหมดวางในหน้า "upload files" ของ GitHub ก็ได้)
3. ไปที่ share.streamlit.io → ล็อกอินด้วย GitHub → "New app"
4. เลือก repo ที่เพิ่งสร้าง · Main file path = `app.py` · กด Deploy
5. รอ ~2 นาที จะได้ลิงก์ เช่น `https://tbs-proctor.streamlit.app` — ส่งให้ทีมได้เลย

**อัปเดตระบบภายหลัง:** แก้ไฟล์แล้ว push ขึ้น GitHub → เว็บอัปเดตเอง
**ความเป็นส่วนตัว:** ตั้ง app เป็น Private + จำกัดเฉพาะอีเมลในทีมได้ที่ Settings → Sharing

---

## วิธีที่ 2 รันบนเครื่องตัวเอง (ง่ายสุด ไม่ต้องสมัครอะไร)
เหมาะถ้าใช้คนเดียว/เครื่องเดียว

```bash
pip install -r requirements.txt
streamlit run app.py
```
เบราว์เซอร์เปิดเองที่ http://localhost:8501
(ถ้าในวงแลนเดียวกันอยากให้เครื่องอื่นเข้า ใช้ `streamlit run app.py --server.address=0.0.0.0`
แล้วให้เพื่อนเปิด `http://<ไอพีเครื่องคุณ>:8501`)

---

## วิธีที่ 3 Docker (สำหรับฝ่าย IT / เซิร์ฟเวอร์คณะ)
```bash
docker build -t tbs-proctor .
docker run -p 8501:8501 tbs-proctor
```
เปิด http://localhost:8501 — เหมาะวางบนเซิร์ฟเวอร์ภายในคณะให้ทีมเข้าถึงถาวร

---

## ข้อมูลที่ต้องเตรียมเวลาใช้งาน
- **ตารางสอน** `.xlsx` (รังสิต — มีชีทรายคณะ AC/BA/FN...)
- **ไฟล์คิว** `.xlsx` (ดึงรายชื่อเจ้าหน้าที่ + ใช้เป็น demand กรณีท่าพระจันทร์)
- **ไฟล์คิวเทอมก่อน** `.xlsx` (ไม่บังคับ — สำหรับยอดยกมา)

## หมายเหตุความปลอดภัย
ไฟล์ที่อัปโหลดจะถูกประมวลผลชั่วคราวเท่านั้น ไม่มีการเก็บถาวร
ถ้าใช้ Community Cloud แบบ Private ข้อมูลจะเห็นเฉพาะคนในทีมที่ได้รับเชิญ
